# Escribir README

## Pasos
1. Lee el código antes de escribir: clases públicas, métodos y tests.
2. Escribe README.md con estas secciones: Qué es · Requisitos ·
   Cómo compilar y probar · Uso (un ejemplo en C#) · Estructura.
3. Usa solo lo que existe en el código. Si algo no está, no lo inventes.
4. Español de Chile, frases cortas.
5. Al terminar, lista los métodos públicos que documentaste.
